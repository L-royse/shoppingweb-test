# 项目总结

## 一、项目成果

1. 完成 Sauce Demo 全流程测试计划与 16 条测试用例设计
2. 搭建基于 POM 的自动化测试框架
3. 实现 16 条自动化用例，全部通过
4. 集成 Allure 生成可视化测试报告
5. 输出企业级测试报告，包含质量评估与改进建议

## 二、技术栈

| 类别 | 工具 |
| :--- | :--- |
| 语言 | Python 3.8 |
| 自动化 | Selenium 4.27 |
| 框架 | Pytest 8.3 |
| 报告 | Allure 2.46 |
| 设计模式 | POM（页面对象模型） |
| 抓包 | Fiddler Everywhere |

## 三、遇到的问题与解决

| 问题 | 原因 | 解决方案 |
| :--- | :--- | :--- |
| 购物车页面元素找不到 | 页面异步渲染，代码执行过快 | 加入显式等待 + 每次重新定位 |
| 多商品添加失败 | React 重渲染导致按钮引用失效 | 循环内重新抓取按钮列表 |
| pytest marker 报错 | 未在 pytest.ini 注册 | 补充 p0/p1/p2 marker |
| allure serve 看不到文件 | 报告生成在临时目录 | 改用 allure generate 存档 |
